# CONTENT ENGINE

ElectroSchema metadata:
Content Types, Fields, Taxonomies, Relations, Workflow, index flags.

Storage:
generic records JSON + terms + relation edges + typed field index.

Professional capabilities use configuration:
- workflow statuses/transitions;
- record history through audit;
- singleton Global Options;
- User Profile content;
- internal data stores;
- groups/repeaters/calculated/conditional fields.

No dynamic table-per-content-type required in Studio.
