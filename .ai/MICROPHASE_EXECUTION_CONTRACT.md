# MICROPHASE EXECUTION CONTRACT

Every microphase file must contain:
- why it exists;
- exact result;
- engine owner;
- Electro responsibility;
- code/package area;
- UI location if any;
- preconditions;
- line-by-line implementation;
- concrete artifacts;
- state/error behavior;
- responsive/a11y;
- tests;
- prohibited duplications;
- tracking evidence.

Agent procedure:
1. read.
2. inspect existing code.
3. verify engine API.
4. add tests.
5. implement smallest correct change.
6. run gates.
7. fix.
8. record evidence.
9. advance.
