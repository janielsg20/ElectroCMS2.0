# THEME / TEMPLATE / STUDIO APPEARANCE / PROJECT KIT SYSTEM

## Studio Appearance
User/workspace preference only.
Controls Studio tokens: mode, colors, typography, icons, radii, shadows, density, control shapes/sizes, menus, spacing, motion and contrast.
Never changes generated project design.

## Frontend/Backend Project Theme
Visual tokens/variants only.

## Template Pack
ElectroDocument kind=template:
Page, Header, Footer, Single, Archive, 404, Section, Modal, Backend Template where applicable.

## Blueprint
Full project/domain configuration:
Schema, documents, backend, queries, form documents, action graphs, roles, themes and optional demo data.

## Project Kit
Install UX combining:
Theme + Template Pack + Blueprint.

Selective install:
Design only / Templates / Structure / Demo Data.

This preserves the original full reusable-package experience without making `Theme` own CMS/data/runtime configuration.
