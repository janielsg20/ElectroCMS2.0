# INSPECTOR SPEC

Tabs order:
1 Content
2 Layout
3 Style
4 Responsive
5 Data
6 Actions
7 Accessibility
8 Advanced

Content:
Puck.Fields/custom Puck fields.

Layout:
layout mode, sizing, flex/grid, gap, order, position, z-index, overflow.

Style:
typography, foreground/background/gradient/image, border/radius/shadow, opacity/effects, hover/focus/active/disabled, transitions/motion.

Responsive:
breakpoint, inherited/override/reset, visibility/order, platform overrides.

Data:
Set From Data, binding source/path, fallback, diagnostics.

Actions:
component events and workflow references.

Accessibility:
role, aria-label, alt, heading level, focus/tab behavior, reduced-motion implications.

Advanced:
stable node ID, Web class/id when supported, safe attributes, display conditions, debug metadata.

No arbitrary JS execution.
